# JobPortal

An interactive job portal deployed at **[jobportal‑gamma‑ten.vercel.app](https://jobportal‑gamma‑ten.vercel.app)** that connects job seekers and recruiters seamlessly.

## 🌐 Live Demo
Access the app here: https://jobportal‑gamma‑ten.vercel.app

## 🧭 Features
- **User Authentication**: Sign up & login for both employers and job seekers
- **Job Search & Filtering**: Browse jobs, search by keywords, filter by location or job type
- **Job Listings**: View detailed job descriptions, eligibility, and responsibilities
- **Apply Functionality**: Submit applications (possibly with resume upload)
- **Employer Dashboard**: Post new jobs, manage listings and applications
- **Responsive Design**: Works well across desktop and mobile

## ⚙️ Tech Stack 
- **Frontend**: React, Next.js (likely deployed via Vercel)
- **Backend / API**: Node.js + Express (or Next.js API routes), perhaps connected to PostgreSQL or MongoDB
- **Authentication**: JWT / session-based (possibly role-based)
- **File Storage**: Cloud storage (e.g. AWS S3) for resume uploads
- **Deployment**: Hosted on Vercel with automatic GitHub integration
